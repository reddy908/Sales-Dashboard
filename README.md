# Sales-Dashboard
I’m excited to share my latest Sales Analytics Dashboard built using Microsoft Power BI.

This dashboard transforms raw sales data into meaningful business insights and provides an interactive view of overall sales performance.

🛠️ Tools Used

• Microsoft Power BI
• Power Query – Data cleaning & transformation
• DAX – Measures & calculations
• Data Modeling
• Data Visualization

📈 Key Insights

🔹 Total Sales: 366.62K
🔹 Quantity Sold: 527
🔹 Total Profit: 34.11K
🔹 Profit Margin: 10.26%
🔹 Analyzed monthly and daily sales trends
🔹 Identified top-performing products and categories
🔹 Compared different sales types and payment modes
🔹 Added interactive filters for Year, Month, Sale Type & Payment Mode

This project helped me strengthen my practical skills in data cleaning, DAX, dashboard development, and business-focused data analysis.
